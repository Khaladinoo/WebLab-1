# Personal Engineering Portfolio

A multi-page website built strictly with semantic HTML5 to showcase technical background, academic milestones, and engineering projects without CSS or JavaScript.

## Theme
The website serves as a **Personal Portfolio** for a computer engineering student. It highlights technical work across software development, computer networking, machine learning algorithms, and system design.

## Challenges Faced
 (Structuring Without CSS): Creating visual separation and readable document flow purely through native HTML semantic elements (`<h1>`-`<h3>`, `<fieldset>`, `<blockquote>`, `<figure>`) without any styling stylesheets.
